# ARCHIT / FUTURE FORM

Premium, cinematic 3D portfolio for Archit Jain. Completely new visual identity developed with [Build Artful Websites](https://github.com/KaranRana21/build-artful-websites).

## Experience

- Kinetic machined platinum **A** sculpture, physically based studio lighting, nested glass core, and orbiting instruments (Three.js).
- Editorial full-screen hero, monumental name composition, luxury-champagne accents.
- Spatial interactive work index: four authentic projects, depth choreography, swipe, arrows, direct selection.
- Genuine Archit portrait, education, Daffodils Software history, documented impact, resume, six original journal links, socials.
- Responsive, keyboard accessible, reduced motion and WebGL fallback.
